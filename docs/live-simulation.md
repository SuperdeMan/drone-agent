# 云端实时仿真入口

这个入口用于亲自体验 M1 的固定巡检：启动任务、查看机载轨迹与相机、暂停/恢复/取消，最后核对裁判与离线证据。它与 `461ec85` 新增的离线证据浏览器互补；自然语言、任务编辑与审批属于 M2（D027）。

## 打开

在仓库根目录的 PowerShell 中运行并保持该窗口开启：

```powershell
$env:UV_DEFAULT_INDEX = 'https://pypi.tuna.tsinghua.edu.cn/simple'
uv run python scripts/dev_stack.py console --port 8768 --artifacts D:/drone-agent-cloud
```

浏览器打开 <http://127.0.0.1:8768>。连接参数沿用 [云端开发指南](cloud-development.md)，不需要新增账号、密钥或 `.env`。仿真在云服务器运行，本机只运行浏览器桥；云端必须已部署包含 D027 实现的提交。若部署版本过旧，页面明确报错，不使用本地仿真代替。

## 体验顺序

1. 保持种子 `7`，点击「开始云端任务」。首次运行先构建仿真镜像；准备期间不会出现飞行轨迹。飞行开始后依次观察起飞、巡检、拍照、返航、降落。
2. 在「已拍证据」查看保存的目标照片。正常任务的五个步骤应已证实，独立裁判为 `completed`，错误成功报告为 0，在线/离线重判一致。
3. 再启动一轮，在巡检按钮可用时点击「暂停」，确认机载已接受且阶段为暂停，再点击「恢复」。暂停上限 120 秒，超过后按既有恢复策略返航。
4. 再启动一轮，点击「取消并安全收尾」。提交取消不代表已经落地；持续观察直到不在空中且上锁，裁判为 `safe_abort`，后续未完成步骤不能算完成。
5. 点击「拉取并核对完整证据」，完成后打开正式离线证据页。复用 `fetch` 的逐文件摘要核对和 `eval.viewer` 的日志/MCAP/影像核对；默认省略大体积 `ulog/`、`sensor/` 文件，页面会如实列为未下载。

任务启动与结束时间随云主机负载变化；浏览器刷新约 1 秒加 SSH 往返时间，不承担 10 Hz 飞行监督。guardian 的原有新鲜度与监督阈值保持不变。

## 操作与连接语义

- 只允许部署版本内的固定巡检与种子 `7/19/41`；不接受任意飞行坐标、控制命令或任务包。
- 云端后台进程持有 `drone-agent` 项目锁，与部署、命令行批次互斥。同一启动 ID 不会再次起飞。
- 暂停/恢复/取消经 executive 的本地操作者通道，绑定当前运行、任务、步骤与 5 秒有效期。迟到请求被拒绝，应先查看最新状态；页面不自动重发。
- 刷新、关闭页面或停止本机桥，不会隐含取消云端任务。重新打开入口会读取当前运行；后台进程异常显示待核对，不自动替代运行。
- 状态断开时显示陈旧快照并禁用操作；任务完成后显示归档快照。最终判定只来自独立裁判，运行中显示「等待最终判定」。
- 相机「最新画面」是最近传感器帧；「已拍证据」是已保存的原始 RGB 无损转换。机载轨迹仅包含本次桥连接收到的样本，完整轨迹在 MCAP 与离线证据页。

## 实现与证据边界

本机 `console/server.py` 仅绑定回环地址，验证 Host、Origin 与内存会话 nonce；无新增云端公开端口。`scripts/remote_live.py` 管理后台任务和操作信箱；运行使用部署中的 `remote_m1.py`、同一镜像与原有五技能。

人工运行产物为 `artifacts/<deployment_id>/m1-<run_id>/interactive-<seed>/`，后台回执为 `live/<run_id>/result.json`。`interactive` 不属于 M1 的固定 22 场景发布矩阵；实际收到的取消或暂停超时决定预期中止，裁判仍独立检查真实效果、安全终态与错误成功。新提交的验证不得引用历史 `eefe76e` 的 66/66 作为本提交结果。

本次实现、准确版本与云端验证范围见 [实时入口验收](live-console-readiness.md)；原始回执在 `docs/verification/`，历史基线按批次保留在 `eval/BASELINES.md`。
