## 抽样与完整性

查看掩码前保存选择规则：对训练集的图像 ID 计算 `SHA256("p6-rescuenet-screen-v1:" + id)`，取排序前 80 个。再依据源掩码是否出现 7 / 8 分组，每组最多取前 8 个配对原图。不根据模型回答或识别成绩选图。

80 张标注的分组结果：

| 源掩码类别 | 张数 | 选取配对原图数 |
|---|---:|---:|
| 仅出现畅通道路 7 | 44 | 8 |
| 仅出现阻塞道路 8 | 11 | 8 |
| 同时出现 7 与 8 | 1 | 1 |
| 没有 7 / 8 标签 | 24 | 8 |
| 合计 | 80 | 25 |

“出现”指该像素值计数大于 0，只是素材筛选分组，不是道路阻塞比例阈值。分层选出的比例也不代表真实场景的异常发生率。没有道路标签的图不能当正常道路，图中其他区域有灾害也不意味着道路一定阻塞。

**7 / 8 是道路的语义标签，不是障碍物实例轮廓。** 已查看图片中，整段道路可能被标成 8，而实际障碍只占其中一部分；不能把每一个标红像素都当作障碍物，也不能用任意截取的红色小块直接生成“有障碍”真值。需要把登记的目标路段与实际障碍位置分别确定。

按官方 ZIP 目录逐条目读取并核验长度和 CRC32，再记录原始字节的 SHA-256；原图与掩码必须同尺寸，标签像素计数重新计算。ZIP 尾部目录原始字节保留，可离线重新解析。不将不完整下载记作成功。

25 对全部完成长度、CRC32、SHA-256、解码、尺寸与像素计数核对；没有重复原图 SHA-256，也没有命中 dHash256 距离 ≤ 10 的候选。GPS 检查仍发现 7 对相机距离 ≤ 100 m 的关系，证明感知哈希未命中不能等价于独立地点。所有图片都有 EXIF 相机型号 `FC220`、拍摄时间和 GPS；拍摄日期为 2018-10-13 / 2018-10-14，EXIF 时区不作推断。

## AI 初审与复核队列

25 张均已查看原图缩略图及源标签叠加图。初审只检查适用性，不把 AI 结论作为独立人工真值：

- 8 张畅通道路图中，周围仍可能有损毁建筑、杂物、阴影或车辆；可作为“周围有灾害不等于目标道路受阻”的开发案例。
- 8 张阻塞道路图提供源作者的阻塞路段标签；`13370`、`14528` 等需要进一步定位实际障碍与目标路段，不能用整片道路掩码代替障碍物轮廓。
- `12494` 同时含 7 / 8；必须分别指定路段，不能只给整图一个正常或异常标签。
- 8 张没有道路标签的图片主要为树林、沙地、岸线、水面或建筑局部，可进入错目标／不可判候选复核，不自动标成“正常”。

已生成 25 项结构化复核队列，目标路段 ID、目标区域、业务标签、实际障碍区域、采集分组、复核人和耗时均保持待填写。来源声明与实际查看结论分栏保留。

## 可用范围与剩余条件

- **补上同来源正反例候选**：源作者提供畅通与阻塞道路的像素标注，优于从垃圾数据集推测障碍标签。仍需指定本项目目标道路区域，并复核业务含义。
- **目标场景仍有差异**：素材来自飓风后的道路与建筑环境，不能直接报告园区日常清障的识别精度。
- **地点和批次隔离尚未成立**：原文件 ID 不是资产或飞行批次 ID。需要结合采集元数据与图像重叠确认分组，不随机拆相邻照片。
- **相邻拍摄已有证据**：`10792` 与 `10799` 的 EXIF 时间相差 21 秒、相机 GPS 相距约 27.32 m，画面存在同一建筑和道路的重叠，应保守视作同一采集组。GPS 是相机位置，不是道路资产位置；100 m 邻近检查只用于发现待复核关系，不是已经批准的独立地点划分规则。
- **邻近照片不能冒充清障对照**：`12876` 与 `12494` 相机距离约 14.59 m、相隔 904 秒，分别含阻塞与混合道路标签，但画面目标范围不同、没有清障事件记录，不能将其构造成清障前后证据。
- **没有清障前后证据**：图像与标注的配对是同一照片的像素标注，不是同一道路清障前后的一对照片。
- **源标签不替代业务真值**：人工复核、登记目标、正常参考、拒判原因及复核用时仍需落实。不得用另一地点的畅通道路作为同资产参考图。
- **已查看样本只作开发材料**：本批图片不再声称是未接触的留出集；完整评测仍须先登记协议与独立采集分组，再校准画像并冻结测试。

正式评测前需明确来源许可适用性；若向作者核实，可具体询问：Figshare `22825511.v1` 等记录的 CC0 是否适用于其中原始图片与像素标注，以及与 GitHub README 的 CC BY-NC-ND 如何对应。本轮没有向作者发送消息。
