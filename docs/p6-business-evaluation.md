# WP-P6-01 道路业务评测实施

本任务集中完成目标业务的数据、标注、计分和准出证据，不改变飞行控制或生产画像。用户于 2026-10-15 指定由本人承担业务复核；这表示复核责任已确定，尚不表示任何样本已获确认。现有 62 张开发照片、26 条开发条目和 33 个模型提案继续保留开发属性。

## 工作与冻结顺序

1. 核验来源许可、图像字节、地点 / 资产 / 批次及近重复组；未知元数据保留缺失，不生成虚构的独立地点。
2. 由用户复核目标范围与业务标签，记录判断依据和提示暴露；标注用时与候选复核用时分开。旧 v6 道路 / 实体记录只能补充几何，不能推出整图正常。
3. 按完整关联组隔离开发、校准和测试，冻结样本量、指标定义与准出判据；没有获确认的数值不写成已批准阈值。
4. 完成道路专用分析入口与校准，再冻结画像和实际调用参数。原设备变化画像要求正常参考图，不能把道路提示图伪装成“正常参考”。
5. 按预登记次数实调、严格回放和计分，报告缺失项、失败项及影响范围，补齐候选验证后形成关闭结论。

## 标注规范草案

基本单元为一次指定道路目标的影像观察，关联真实 `asset_id`、`site_id`、`capture_batch_id` 和图像摘要。多个窗口、裁剪、同图两个目标及近邻帧不能自动成为独立资产或采集批次。

| 标签 | 定义 |
|---|---|
| `normal` | 已检查完整目标范围，未发现符合当前口径的实体遮挡；未检查或看不清不能选此项。 |
| `obstacle` | 有可辨认的实体或实体群实际进入指定道路范围；无物体最小尺寸 / 占用比例门槛。单件难以分离或材质细类未知不自动否定存在。 |
| `indeterminate` | 实体存在、目标边界或图像质量不足以支持确定判断；必须写原因。 |
| `wrong_target` | 可信任务定义与影像不匹配，或所需道路目标没有出现在影像中；不能仅凭源数据没有道路标签推断。 |

普通车辆出现不自动构成障碍；缺少判断其阻碍关系的上下文时保留不可判。阴影、标线、路面破损与实体分开。标签必须包含实际复核者、依据、时间、是否看过模型 / 源标签提示及是否完成整个目标检查。AI 建议、源分割类别和 QA 夹具均不能自行升级为本业务人工标签。

类型词表、困难类别覆盖和具体数量仍待随正式协议冻结；主分类评测与对象级定位评测分开，不能用一个宽框命中多个对象来宣称对象召回率。

## 用户已采用的第一版验收目标

以下工程验收目标于 2026-10-15 经用户回复“采用这版目标，继续补齐数据”确认。**目标已采用，数据清单和正式运行范围尚未冻结；这些不是行业标准，也不是现有模型已达到的成绩。** 原工作包要求建立目标业务评测并报告五类指标；本协议把“满足什么结果才采用”明确下来，不能从 P4 电路板成绩直接继承。验收用于有人复核的道路障碍候选筛查，不用于无人值守的安全通行判断。

| 项目 | 建议要求 | 计分约束 |
|---|---|---|
| 正常目标误报 | 每 100 个正常资产 ≤ 5 次 | 每个资产只有一个预先指定的主观察；正常分母至少 100；另报全部可判资产分母 |
| 按类型漏检 | 每类 ≤ 20% | 障碍主观察至少 100，每个已冻结类型至少 30；拒判计入漏检，错类型也计入该类型漏检 |
| 确定性样本覆盖 | ≥ 90% | 分母为真值正常 + 有障碍；不能通过大量拒判回避误报 / 漏检 |
| 不可判 / 错目标被判正常 | 0 次 | 两类各至少 30；这里的零是样本内零次，不表示真实错误概率为零 |
| 跨次稳定性 | 可判且结论一致的配对 ≥ 90% | 至少 30 对，覆盖至少 15 个不同资产；须为同资产、同状态、不同真实采集，双拒判不算成功 |
| 人工复核负担 | 有效查看时间 p95 ≤ 120 秒 | 所有候选 / 拒判主观察都需真实计时，至少 30 条；报告中位数、p95、总用时和覆盖率 |

初始测试集建议至少 **260 个不同资产的主观察**（正常 100 + 障碍 100 + 不可判 30 + 错目标 30），另有满足配对要求的重复采集；不能靠裁剪、同图多个窗口或同一资产多拍扩充主观察分母。测试覆盖至少 3 个经核对的地点，任一地点不超过主观察的 50%。校准集另需至少 60 个主观察（20 + 20 + 10 + 10），与测试及开发在资产、地点、批次和近重复组上完全隔离。缺陷词表暂建议 `debris`（非植被的散落 / 堆积物）、`vegetation`（侵入道路的植被）、`other_entity`（其他已确认的实体），不得把同一实体重复填多个类型以凑覆盖；同图多个不同类型可以同时记录。

这些样本量是首次 S2 的可审查起点，不足以证明上述门槛在所有道路上都有统计保证。所有比例同时报告分子、分母和 Wilson 95% 区间；例如 100 个正常资产有 5 次误报，其区间上界约 11.2%，并不能证明总体误报率的上界为 5%。建议本轮判据采用预登记的观察值，区间如实披露；若要求置信上界也达标，需要另行设计更大样本，不能在跑完测试后切换统计口径。

用户同时承担真值标注和候选复核时，第二阶段必须记录已经看过真值，报告为“熟悉样本的复核耗时”；该计时不代表陌生操作员效率。标注目标、查找所有实体的时间独立记录，不能混入日常候选复核。重复回看不增加独立复核样本数。

真实清障前后证据仍是当前缺口。跨次同状态配对不能替代清障效果验证，静态洪灾图片也不能证明现场处置效果；本次采用目标没有删除既有交接中的这一缺口。正式协议须先写明能验收的范围，再冻结清单和运行次数。`protocol-draft.json` 记录实际用户确认，状态为 `targets_approved_data_pending`；不能提前改为 `frozen`。数据或结果未达标时保留 `missing` / `failed`，不追着测试成绩降阈值。

## 五类指标的计分约定

- **误报**：同时报告正常观察中误报数、正常观察总数和每 100 次正常资产观察的误报数；另报每 100 次全部确定性观察的误报数，避免分母混淆。每资产 / 每地点样本数单列。
- **按类型漏检**：对包含某类障碍的观察，报告未报候选的比例，以及未正确给出该类型的比例；这是观察级指标，不冒充实例级召回率。拒判也进入漏检分母，不靠全部拒判得到好成绩。
- **拒判与原因**：报告总拒判率、确定性样本覆盖率和原因分布；将不可判 / 错目标错误输出为正常单列。没有结果不能自动记作正常。
- **跨次稳定性**：只使用经复核确认同资产、同状态的不同真实采集对；同时报告双方可判覆盖率、可判结论一致率及未解决对。双方都拒判不算稳定性成功，重复文件不算新采集。
- **人工复核用时**：只统计真人的候选 / 拒判复核会话，报告样本数、覆盖率、中位数和 p95，并区分提示 / 既有标签暴露。制作真值的标注时间另列，不混作日常复核效率。

所有百分比同时保留分子 / 分母。没有分母时返回缺失，不填 0；脚本和回放只能验证计算链路，不计成新的实调成绩。模型调用必须另有冻结来源与严格回放证据，单凭导入一张结果表不能准出。

## 当前实现边界

本轮先落地离线数据准入和计分核心，入口为 `scripts/p6_business_eval.py`。协议草案位于 `eval/s2/road_business_v1/protocol-draft.json`；批准状态、正式数量和数值判据未齐时，准出结果保持 `missing`。它不启动模型、服务或数据库迁移。

正式道路分析入口、校准及唯一冻结测试仍依赖合格数据与人工记录，不把已有逐提案探针当成穷尽整个道路的识别结果。使用权、独立性、跨次及实际复核证据未齐时不关闭 WP-P6-01。真实清障效果的验证范围须在正式协议中明确，不能从静态图或模拟清障推断现场效果。
