# P6 提案定位对照页

本工具承接 [v9 实调](p6-candidate-groups-development.md)的定位风险，为六个道路目标、33 个固定提案提供带 ID 的全图与局部对照。它只读展示既有证据，不调用模型、不生成新候选、不保存人工结论，也不减少人工待办。

## 画面与操作约定

- 同一提案在左侧全图和右侧局部中同步显示；原框是复核窗口，不能作为精确实体框。点击清单或全图中的提案框切换，提供前后项和键盘导航。
- 可切换原始分辨率图、实际发送给模型的缩小原图、实际发送给模型的道路提示图。三种图使用同一归一化坐标，明确标注各自分辨率；放大不创造新细节。
- 局部支持带周边观察、贴近窗口、放大 / 缩小和拖动；始终保留全图位置参考。道路提示是源支持域，不是已登记资产边界，孔洞不能直接视作道路外。
- 保留全部 33 项和原模型分组；可筛选 12 项优先复核项或单个道路目标。空筛选明确显示无结果，不保留与筛选不符的活动提案。
- 默认定位到 `12892-p01` 的范围矛盾。模型说明与条件几何在“开发参考”中展示，明确其非真值属性；查看页面不计作人工确认。

## 来源与边界

构建器先核对 v9 验证回执、原始录制 / 汇总 / 队列摘要、33 项身份和分组一致性，再核对原图及三种视图的字节与尺寸。输出到新的仓库外目录，已有包不覆盖；包身份绑定页面源码、构建器、来源和数据。图像只按原字节复制，局部用 SVG 视窗展示，不重采样、不生成新的标注位图。

这是受模型提示影响的公开材料开发工具，不能用于宣称独立盲评或模型准确率。v6 的道路 / 实体登记工具保持原状；本页不提供登记、导入人工记录或自动关单入口。正式真值仍需独立复核，P6 未准出。
