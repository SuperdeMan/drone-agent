# 世界表示

[返回架构总览](00-overview.md) · [契约](02-contracts.md) · [M3 实施计划](../m3-implementation.md) · [运营层](09-operations.md)

**当前与目标：** M2 已使用 `WorldFact` / `Evidence` 契约、版本化场景登记表、实时观测及事件 / 证据账本；真值隔离和预测事实不能满足前置条件已有契约测试。`TruthWorld`、`BeliefWorld`、`PredictedWorld` 是架构概念，不能据名称推断存在同名运行服务。M3-SITL 已实现深度局部几何与候选信念事实；完整语义场景图及跨机器人增量同步仍待实现。

## 1. 三种世界

| 世界 | 内容 | 使用者 | 能否作为当前事实 |
|---|---|---|---|
| **TruthWorld** | 仿真真值（位姿、对象、碰撞、真实异常标注） | 评测裁判、标注、离线分析 | 不能提供给被测 agent；进程级隔离 |
| **BeliefWorld** | 感知与估计得到的世界 | 运行时规划、技能执行、协同 | 可以，但每条事实必须带时间、坐标系、版本与不确定性 |
| **PredictedWorld** | 模型预测的未来（世界模型 / 轨迹预测） | 候选动作评估、研究策略 | 不能；`world_kind=predicted` 的事实不能满足 `preconditions` |

裁判只读 TruthWorld，agent 只读 BeliefWorld；这是评测可信的前提。

## 2. BeliefWorld 双层表示

### 2.1 几何层（局部）

- M3 已实现深度体素地图、局部二维规划栅格与邻近障碍点，供短时域规划和 CBF 距离约束使用；完整 ESDF 是可替换的目标表示，当前代码未实现独立 ESDF 服务。
- 高频、机载、不跨机器人共享（共享代价高且语义弱）。

### 2.2 语义场景图（可共享）

- 节点：资产（`asset`）、区域（`zone`）、观测（`observation`）、异常（`anomaly_candidate`）、机器人（`robot`）、共享资源（`resource`）。
- 边：空间包含、邻接、观测关系（`observed_by`, `rechecked_by`）、任务关系（`target_of`）。
- 每个节点带：`frame_id`、`map_version`、位置 + 协方差、`timestamp`、`valid_until`、`source`、`confidence`、`evidence_refs`。
- 开放词汇：语义标签允许自由文本 + 可选嵌入；对象身份优先用资产库 ID 接地，接地失败时保留「候选」状态。
- 跨机器人传输的是场景图**增量**（新增 / 更新 / 失效节点），带宽受限时优先级：异常候选 > 观测 > 区域更新。

## 3. 空间契约

| 项 | 约定 |
|---|---|
| 全局坐标 | WGS84（经纬高，海拔参考显式：AMSL / 椭球 / AGL） |
| 局部坐标 | ENU，原点带 `map_version`；机器人 body 为 FLU |
| 姿态 | 四元数（x, y, z, w），ENU 参考 |
| 时间 | UTC 纳秒；每台机器人报告时钟源与估计偏差 |
| 不确定性 | 3×3（位置）或 6×6（位姿）协方差；缺失协方差的位置不进入场景图 |
| 地图版本 | 任何几何 / 语义地图变更升 `map_version`；旧版本事实需重投影或失效 |
| 转换 | 跨坐标系转换必须合成不确定性（Jacobian 传播或保守膨胀） |

座舱导航拿到的一个地图点，不能未经坐标系与误差校验直接成为飞行目标。

## 4. 记忆分层

| 层 | 内容 | 生命周期 |
|---|---|---|
| 工作记忆 | 当前任务包、当前技能实例状态、最近观测 | 任务内 |
| 情节记忆 | 每次任务的事件流 + 证据索引（MCAP + 事件日志） | 永久（可归档） |
| 语义记忆 | 资产库、区域定义、历史异常、场景图快照 | 版本化 |
| 程序记忆 | 技能清单与实现版本、恢复策略图 | 版本化，审批变更 |

LLM 的上下文由检索构建（资产、历史异常、相关事件），不把整个场景图塞进提示。

## 5. 感知产物进入 BeliefWorld 的门槛

1. 有坐标系、时间、来源、协方差。
2. 来源为模型时带模型版本与置信度；置信度低于场景阈值的只作为 `candidate`。
3. `sim_truth` 来源的事实在非评测进程中被拒绝（防止真值泄漏到被测 agent）。

## 6. 运营事实与检索（P1/P4，设计）

Site / Dock / Robot 状态使用有身份、版本、观测时间和有效期的结构化目录；设备、环境、能源和物理占用在派遣时重新读取，不能从 RAG 的旧文本恢复为当次事实。项目授权同时过滤检索结果和证据访问。

说明书、SOP、检查规范属于静态知识；历史异常与任务账本属于情节证据；实时状态属于带 TTL 的动态事实。向量命中只提供候选资料，不产生当前前置条件。跨项目复用影像、位置或语义图必须重新检查访问授权。

S0 模拟器维护的状态真相只供逻辑裁判；被测工作流 / 调度器经正式状态契约读取观测，可出现延迟和未知。S1 的 Gazebo 真值隔离继续保留；S2 测试标注不可混进模型上下文。InspectionFinding 是带来源的业务候选，不提升飞行效果或安全判定。
