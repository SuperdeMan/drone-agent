# 独立道路影像观察说明

只读取自己的 assignment、actual-context 和分配的原图/guide，及自己生成的辅助裁片/记录；不读取其他作者/核验者、全量交接、模型提示/输出、源业务类别或仓库源码。先等待自己的 actual-context.json 确认实际 fork-none 登记后再看图。初标不看任何首稿；二审只看自己分工明确提供的首稿，不称盲于首稿。

## 固定目标和判断

- 目标是固定 A/B 之间的主路完整横截面；centerline 只定位，不是边界或答案。不得移动端点、缩短范围或为避开实体缩小道路。
- 接入口或停车前场相连时，按接入口两侧可辨认的主路边缘及连续宽度，不自动纳入整片前场。树冠、深阴影等遮挡完整边缘而无法可靠延续时继续不可判，不补造冠下边界。
- `normal`：已检查完整固定道路范围且未发现符合口径的实体遮挡。
- `obstacle`：有可辨认的实体/群进入该范围；没有实体尺寸或占比门槛。对象类型为 `debris`、`vegetation`、`other_entity`，均须真实归一化多边形。
- `indeterminate`：边界、实体、质量或阻碍关系不明，说明实际原因；未知不能按正常处理。
- `excluded_source`：缺可用影像或无可标道路目标。普通分工没有事前预期任务，不能擅自标 `wrong_target`。
- 普通车辆出现不自动构成障碍；缺其阻碍关系上下文时保留不可判。阴影、标线和路面破损与实体分开。
- 不以类别配额、接受率或推进速度影响结论，不从源许可、几何或 alpha 推断正常或物理身份。

## 实际检查与文件

必须实际逐张查看原图和 guide，使用 `view_image` 并把图像返回到自身视觉上下文；原图看过，guide 仅为定位。大图须按原生像素检查整段、两端和两侧，必要时在自己的 worker_dir 保存并实际查看原生裁片；不编辑原图或 guide，不把裁片计新素材。`inspection_files` / `inspected_files` 记录真实完整路径。

每完成 2–4 项，将已有实际观察写进 `first-payload-progress-v1.json` 或 `review-payload-progress-v1.json`，状态 `in_progress`。全部分配项实际完成才写最终 payload，不能用文件修改时间冒充观察时间或编造真人用时。推荐英文可读说明，以 Python UTF-8 或 apply_patch 写文件，避免 PowerShell 中文管道损坏。

不要运行入库 CLI，不创建 suggestions.json / reviews.json，不改共享登记、其他 worker 文件、源图、环境、代码或服务；不删除、提交、推送、联网下载、安装依赖。root 只做确定性存储，视觉裁定由实际观察者负责。

## 初标输出

最终文件 `first-payload.json` 的键：`author_id`（自己的 ID）、`assignment_sha256`（实际 SHA）、`status="complete"`、`human_reviews_created=0`、`formal_release_eligible=false`、`full_assigned_targets_checked=true`、`rows`。

每行严格恰好：`sample_id,image_sha256,target_brief,target_polygon,verdict,objects,notes,uncertainties,inspected_at,inspection_files`。

多边形使用 [0,1] 范围内有效、不自交、至少 3 点的真实轮廓。normal/obstacle 必须有整段真实道路 polygon；未知可为 null。只有 obstacle 的 objects 非空，每项仅 `defect_type,polygon`；其余 verdict 的 objects=[]，不确定实体放 notes/uncertainties。后两项路径/不确定项为 list[str]，inspected_at 是真实观察时刻且含时区。

## 二审输出

最终文件 `review-payload.json` 的键：`reviewer_id`、`assignment_sha256`、`status="complete"`、`human_reviews_created=0`、`formal_release_eligible=false`、`full_assigned_target_checked=true`、`rows`。

每行严格恰好：`sample_id,decision,findings,changes,inspected_files,original_image_checked`。decision 为 accepted/revised，accepted 的 changes={}；revised 的 changes 非空且仅可改 `target_brief,target_polygon,verdict,objects,notes,uncertainties`。findings 为非空 list[str]，基于实际图像说明依据/修订；修改后的完整最终行遵守初标 schema。original_image_checked=true 仅在实际查看后记录，inspected_files 含实际原图与 guide。

二审同时写 `physical-target-findings-v1.json`：绑定 assignment SHA、每项 image SHA 和 fixed_world_scope.freeze_scope_sha256，记录 `target_present`、`fixed_scope_identifiable`、`full_target_boundary_visible`（true/false/null）及 evidence。不可用影像保持 unknown/null，不凭地图推断物理目标不存在。这只是同次二审的补充观察，不称另一次盲身份核验，也不自动授予不同资产独立性。

最终报告文件路径/SHA、分配项是否全部真实检查、修订/未解决状态和仅读范围；不伪造人工真值或真人计时。
